# Research Study Tracker

A hands-on Python project for practicing data cleaning, validation, analysis, and research study management in preparation for technical coding interviews.

## Project Structure

- `studies.py` — Python functions for managing research studies
- `tests/test_studies.py` — Automated tests using pytest
- `studies.ipynb` — Interactive Python practice notebook

## Features

- Retrieve research studies by ID
- Filter studies by status
- Validate and clean research study data (in progress)
- Analyze and summarize study metrics (planned)

## Running Tests

From the repository root:

```bash
python -m pytest -v
```

## Technologies

Python, Jupyter Notebook, pytest

Planned: pandas, Pydantic, FastAPI, SQLAlchemy
